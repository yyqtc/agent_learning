# 智慧酒店包提交成功页面

## 页面概述

智慧酒店包提交成功页面是企业产品预约模块的最终反馈页面，以全屏弹窗形式展示预约提交成功的状态，提供用户友好的成功反馈和后续操作指引，包括返回首页和查询在途订单等功能。

## 功能特点

### 1. 成功状态展示
- **成功图片**：显示预约成功的视觉反馈图片
- **状态提示**：清晰的预约成功状态说明
- **用户引导**：友好的用户操作指引

### 2. 导航功能
- **返回首页**：提供返回首页的快捷入口
- **查询在途订单**：支持查看当前在途的订单状态
- **返回上一页**：支持返回上一级页面
- **关闭页面**：提供关闭当前页面的选项

### 3. 页面交互
- **固定导航栏**：顶部固定导航栏显示页面标题
- **响应式布局**：适配移动端显示
- **消息通信**：与父页面的完整消息传递机制
- **状态管理**：完整的页面状态和流程管理

### 4. 用户体验
- **视觉反馈**：清晰的成功状态视觉展示
- **操作便捷**：提供多种便捷的操作选项
- **信息完整**：展示完整的预约成功信息
- **流程闭环**：完成整个预约流程的闭环

### 核心功能模块

#### 1. 导航控制
```javascript
// 返回上一页
function goBack() {
    if (window.parent !== window) {
        window.parent.postMessage({ type: 'closeSuccessModal' }, '*');
    } else {
        window.history.back();
    }
}

// 关闭页面
function closePage() {
    if (window.parent !== window) {
        window.parent.postMessage({ type: 'closeSuccessModal' }, '*');
    } else {
        window.close();
    }
}
```

#### 2. 页面跳转
```javascript
// 返回首页
function redirectToHome() {
    if (window.parent !== window) {
        window.parent.postMessage({ type: 'closeSuccessModal' }, '*');
    } else {
        window.close();
    }
}

// 查询在途订单
function onTheWay() {
    if (window.parent !== window) {
        window.parent.postMessage({ 
            type: 'closeSuccessModal',
            action: 'redirectToOnOrder'
        }, '*');
    } else {
        window.location.href = '智慧酒店包在途订单页面.html';
    }
}
```

## 数据流程

### 1. 页面加载流程
1. 页面加载完成
2. 初始化页面元素
3. 设置事件监听器
4. 显示成功状态

### 2. 用户操作流程
1. 用户查看成功状态
2. 选择后续操作
3. 执行相应的跳转或关闭操作
4. 向父窗口发送相应消息

### 3. 消息处理流程
1. 接收用户操作
2. 判断当前页面环境（iframe或独立页面）
3. 执行相应的处理逻辑
4. 发送消息到父窗口或执行本地操作

## 使用说明

### 页面访问
1. 通过信息填写页面的"提交预约"按钮进入
2. 支持直接访问进行独立测试
3. 作为整个预约流程的最终页面

### 操作选项
1. **返回首页**：点击"返回首页"按钮回到首页
2. **查询在途订单**：点击"查询在途订单"按钮查看订单状态
3. **返回上一页**：点击左上角返回按钮返回上一页
4. **关闭页面**：点击左上角关闭按钮关闭当前页面

### 注意事项
- 页面设计为移动端优先，建议在手机设备上测试
- 所有操作都会向父窗口发送相应的消息
- 页面支持在iframe中运行和独立运行两种模式
- 成功图片需要确保文件路径正确
