# 智慧酒店包信息填写页面

## 页面概述

智慧酒店包信息填写页面是企业产品预约模块的信息收集组件，以底部弹出的形式展示用户信息填写界面，支持安装地址、详细地址、联系方式和备注信息的录入，并集成产品规格信息展示和提交成功流程。

## 功能特点

### 1. 信息收集功能
- **安装地址**：城市选择和具体楼宇选择
- **详细地址**：楼栋和房间号的分段输入
- **联系方式**：姓名和电话号码的并行输入
- **备注信息**：可选的备注说明输入

### 2. 产品信息展示
- **产品缩略图**：显示产品图片
- **价格信息**：实时显示当前选择的价格和套餐类型
- **规格详情**：展示已选择的套餐类型、带宽、电视、屏幕定制等信息
- **动态更新**：根据规格选择结果动态更新显示内容

### 3. 表单验证机制
- **必填项验证**：安装地址、详细地址、姓名、电话为必填项
- **格式验证**：手机号码格式验证
- **实时反馈**：输入过程中的即时验证反馈
- **错误提示**：清晰的错误信息提示

### 4. 弹窗交互设计
- **底部弹出**：从屏幕底部滑入的弹窗效果
- **返回功能**：支持返回上一级页面
- **提交流程**：完整的表单提交和成功反馈流程
- **消息通信**：与父页面的完整消息传递机制

        updateProductInfo(selectionData);
    }

## 数据流程

### 1. 页面初始化流程
1. 页面加载完成
2. 监听父窗口消息
3. 接收规格选择数据
4. 更新产品信息显示
5. 显示弹窗动画

### 2. 数据更新流程
1. 接收来自规格选择页面的数据
2. 解析JSON格式的选择数据
3. 计算价格和套餐类型
4. 更新产品信息显示
5. 更新底部价格显示

### 3. 表单提交流程
1. 收集所有表单数据
2. 执行数据验证
3. 合并规格数据和表单数据
4. 显示提交成功弹窗
5. 处理后续流程

### 4. 页面关闭流程
1. 用户点击返回按钮
2. 向父窗口发送关闭消息
3. 执行关闭动画
4. 返回上一级页面

## 使用说明

### 页面访问
1. 通过规格选择弹窗的"确认"按钮进入
2. 支持直接访问进行独立测试
3. 通过URL参数传递规格选择数据

### 操作流程
1. **查看产品信息**：确认已选择的规格和价格
2. **填写安装地址**：选择城市和具体楼宇
3. **填写详细地址**：输入楼栋和房间号
4. **填写联系信息**：输入姓名和电话号码
5. **添加备注**：可选填写备注信息
6. **提交预约**：点击"提交预约"按钮
7. **查看结果**：在成功页面查看提交结果

### 注意事项
- 页面设计为移动端优先，建议在手机设备上测试
- 所有必填项都必须完整填写才能提交
- 手机号码必须符合中国大陆手机号格式
- 产品信息会根据规格选择自动更新显示

## 表单字段说明

### 必填字段
- **安装地址**：选择具体的安装楼宇
- **详细地址**：楼栋号和房间号
- **姓名**：联系人姓名
- **电话**：联系人手机号码

### 可选字段
- **备注**：其他需要说明的信息

### 自动填充字段
- **城市**：默认选择广州市
- **产品信息**：根据规格选择自动更新
