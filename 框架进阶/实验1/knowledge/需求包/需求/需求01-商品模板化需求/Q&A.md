# 企业产品订购模版 - HTML原型页面

## 项目概述

本项目包含企业产品订购流程的HTML原型页面，主要用于移动端展示和用户交互测试。所有页面都采用响应式设计，适配手机端显示。

## 页面结构
![商品详情页](images/详情页.png)

### 1. 智慧酒店包产品详情页.html
- **功能**：展示产品详情，包括产品标题、规格选择等
- **特点**：
  - 动态更新产品标题格式：`【爱企商城】智慧酒店包{价格}元{套餐类型}`
  - 集成规格选择弹窗
  - 支持产品分享功能
  - 按钮文案：立即订购

### 2. 智慧酒店包规格选择弹窗.html
- **功能**：产品规格选择界面
- **特点**：
  - 产品缩略图展示
  - 价格选择选项
  - 套餐类型选择（月包/年包）
  - 与父页面数据联动
  - 支持关闭和提交操作

### 3. 智慧酒店包信息填写页面.html
- **功能**：订购流程的容器页面
- **特点**：
  - 动态加载子页面（iframe方式）
  - 处理页面间的消息传递
  - 按钮文案：提交订购
  - 支持完整的订购流程

### 4. 温馨提示.html
- **功能**：防范电信网络诈骗承诺书页面
- **特点**：
  - 20秒强制阅读倒计时
  - 承诺书内容展示
  - 勾选框确认机制
  - 重点文字高亮显示
  - 按钮文案：我已阅读（20S）

### 5. 身份证上传.html
- **功能**：身份证件照上传页面
- **特点**：
  - 身份证正反面上传
  - 拍照示例展示
  - 操作指南入口
  - 示例弹窗功能
  - 下一步按钮跳转

### 6. 合同上传.html
- **功能**：合同签订信息填写页面
- **特点**：
  - 基本信息填写
  - 套餐信息展示
  - 签约方式选择（线上/线下）
  - 操作指南入口
  - 业务流程提醒

### 7. 智慧酒店包提交成功弹窗.html
- **功能**：订购成功提示页面
- **特点**：
  - 成功状态展示
  - 返回首页功能
  - 查询在途订单功能
  - 顶部导航栏：订购成功
  - 手机端适配

## 技术特点

### 响应式设计
- 所有页面都采用 `max-width: 375px` 的手机端适配
- 使用 `margin: 0 auto` 实现居中显示
- 支持不同屏幕尺寸的响应式布局

### 页面通信
- 使用 `postMessage` API 实现 iframe 间的数据传递
- 支持页面跳转和状态管理
- 完整的消息类型定义

### 交互功能
- 文件上传模拟（身份证上传）
- 倒计时功能（温馨提示页面）
- 弹窗展示（操作指南、示例图片）
- 表单验证和状态管理

### 样式设计
- 统一的视觉风格
- 现代化的UI设计
- 良好的用户体验
- 一致的色彩搭配

## 使用说明

### 启动方式
1. 直接打开 `智慧酒店包信息填写页面.html` 作为入口页面
2. 或者单独打开任意页面进行测试

### 测试流程
1. 产品详情页 → 规格选择 → 信息填写
2. 温馨提示 → 身份证上传 → 合同上传 → 提交成功

### 注意事项
- 所有页面都设计为移动端优先
- 图片资源使用 base64 编码的占位图
- 实际部署时需要替换为真实的图片资源
- 文件上传功能为模拟实现，实际项目中需要后端支持
