# 温馨提示页面

## 页面概述

温馨提示页面是企业产品订购模块的重要合规组件，主要用于展示防范电信网络诈骗的承诺书内容，要求用户仔细阅读并同意相关条款后才能继续订购流程。该页面采用移动端优先设计，提供清晰的提示信息和用户友好的交互体验。

## 功能特点

### 1. 温馨提示展示
- **重要提示**：清晰展示身份证等资料上传要求
- **安全提醒**：强调防范电信网络诈骗的重要性
- **阅读要求**：要求用户认真阅读20秒以上

### 2. 承诺书内容
- **基本承诺**：严格遵守国家相关法律法规
- **防范措施**：详细的防范电信网络诈骗措施
- **责任声明**：明确用户责任和义务
- **其他条款**：补充说明和生效条件

### 3. 交互控制机制
- **倒计时功能**：20秒倒计时，确保用户充分阅读
- **勾选确认**：必须勾选同意承诺书才能继续
- **按钮状态管理**：根据阅读时间和勾选状态控制按钮可用性
- **流程控制**：完成确认后跳转到身份证上传页面

### 4. 用户体验优化
- **视觉层次**：清晰的标题、内容和按钮层次
- **颜色提示**：使用红色突出重要信息
- **动画效果**：淡入动画和脉冲效果
- **响应式设计**：适配移动端显示

### 核心功能模块

#### 1. 倒计时功能
```javascript
let countdown = 20;
let countdownInterval;
let isChecked = false; // 默认不勾选
let canSubmit = false;

// 开始倒计时
function startCountdown() {
    countdownInterval = setInterval(function() {
        countdown--;
        
        // 更新按钮文字显示倒计时
        updateButtonState();
        
        if (countdown <= 0) {
            clearInterval(countdownInterval);
            canSubmit = true;
            updateButtonState();
        }
    }, 1000);
}
```

#### 2. 勾选状态管理
```javascript
// 切换勾选状态
function toggleCheckbox() {
    isChecked = !isChecked;
    const checkbox = document.getElementById('agreementCheckbox');
    
    if (isChecked) {
        checkbox.classList.add('checked');
    } else {
        checkbox.classList.remove('checked');
    }
    
    updateButtonState();
}
```

#### 3. 按钮状态控制
```javascript
// 更新按钮状态
function updateButtonState() {
    const confirmBtn = document.getElementById('confirmBtn');
    
    if (isChecked && canSubmit) {
        confirmBtn.classList.add('enabled');
        confirmBtn.disabled = false;
        confirmBtn.textContent = '我已阅读（20S）';
    } else if (!isChecked) {
        confirmBtn.classList.remove('enabled');
        confirmBtn.disabled = true;
        if (canSubmit) {
            confirmBtn.textContent = '请先勾选同意承诺书';
        } else {
            confirmBtn.textContent = `我已阅读（${countdown}S）`;
        }
    } else if (!canSubmit) {
        confirmBtn.classList.remove('enabled');
        confirmBtn.disabled = true;
        confirmBtn.textContent = `我已阅读（${countdown}S）`;
    }
}
```

#### 4. 确认提交功能
```javascript
// 确认提交
function confirmAgreement() {
    if (!isChecked || !canSubmit) {
        return;
    }
    
    console.log('用户确认提交防范电信网络诈骗承诺书');
    
    // 直接跳转到身份证上传页面
    if (window.parent !== window) {
        // 通知父窗口关闭当前页面并跳转到身份证上传页面
        window.parent.postMessage({ 
            type: 'closeAgreementModal',
            action: 'redirectToIdUpload'
        }, '*');
    } else {
        // 如果不在iframe中，直接跳转
        window.location.href = '身份证上传.html';
    }
}
```

#### 5. 页面初始化
```javascript
// 页面加载完成后开始倒计时
document.addEventListener('DOMContentLoaded', function() {
    console.log('温馨提示页面已加载');
    
    // 初始化按钮状态
    updateButtonState();
    
    // 开始倒计时
    startCountdown();
    
    // 添加淡入动画
    document.querySelector('.content-container').classList.add('fade-in');
});
```

## 数据流程

### 1. 页面加载流程
1. 页面加载完成
2. 初始化按钮状态
3. 开始20秒倒计时
4. 添加淡入动画效果

### 2. 用户交互流程
1. 用户阅读温馨提示内容
2. 用户阅读承诺书内容
3. 倒计时结束后允许勾选
4. 用户勾选同意承诺书
5. 按钮变为可用状态
6. 用户点击确认按钮

### 3. 提交流程
1. 验证勾选状态和倒计时状态
2. 发送消息通知父窗口
3. 跳转到身份证上传页面
4. 完成温馨提示流程

## 使用说明

### 1. 页面访问
- 通过信息填写页面跳转访问
- 支持iframe嵌入和独立页面访问
- 自动适配移动端和桌面端

### 2. 操作流程
1. 仔细阅读温馨提示内容
2. 阅读防范电信网络诈骗承诺书
3. 等待20秒倒计时结束
4. 勾选同意承诺书
5. 点击确认按钮继续流程

### 3. 注意事项
- 必须等待20秒倒计时结束才能勾选
- 必须勾选同意承诺书才能继续
- 承诺书内容需要认真阅读
- 确认后会自动跳转到身份证上传页面
