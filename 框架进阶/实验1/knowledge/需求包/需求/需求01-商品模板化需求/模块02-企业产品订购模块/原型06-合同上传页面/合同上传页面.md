# 合同上传页面

## 页面概述

合同上传页面是企业产品订购模块的重要签约组件，主要用于展示合同签订相关信息，包括基本信息确认、套餐信息展示、签约方式选择和业务流程提醒。该页面采用移动端优先设计，提供清晰的签约流程指引和用户友好的交互体验。

## 功能特点

### 1. 基本信息展示
- **证件号码**：显示用户身份证号码
- **联系电话**：显示安装师傅联系电话
- **经办人身份**：选择经办人是否为法人
- **信息确认**：确保用户信息准确无误

### 2. 套餐信息展示
- **套餐名称**：显示订购的套餐类型
- **套餐规格**：展示套餐的具体规格和价格
- **数量信息**：显示订购数量
- **信息汇总**：完整展示订购信息

### 3. 签约方式选择
- **线上签约**：支持在线电子签约
- **线下签约**：支持线下传统签约
- **签约教程**：提供签约操作指南
- **客户经理联系**：线下签约的联系方式

### 4. 业务流程指引
- **流程提醒**：根据选择显示不同的业务流程
- **操作指南**：提供详细的操作步骤说明
- **状态提示**：清晰的状态和进度提示
- **帮助支持**：完整的帮助和支持功能

### 核心功能模块

#### 1. 经办人身份选择
```javascript
let selectedAgent = 'yes';
let selectedSigningMethod = 'online';

// 选择经办人是否为法人
function selectRadio(type) {
    selectedAgent = type;
    
    const radioYes = document.getElementById('radioYes');
    const radioNo = document.getElementById('radioNo');
    
    if (type === 'yes') {
        radioYes.classList.add('checked');
        radioNo.classList.remove('checked');
    } else {
        radioYes.classList.remove('checked');
        radioNo.classList.add('checked');
    }
    
    // 更新业务流程提醒
    updateProcessReminder();
}
```

#### 2. 签约方式选择
```javascript
// 选择签约方式
function selectSigningMethod(method) {
    selectedSigningMethod = method;
    
    const onlineSigning = document.getElementById('onlineSigning');
    const offlineSigning = document.getElementById('offlineSigning');
    
    if (method === 'online') {
        onlineSigning.classList.add('active');
        offlineSigning.classList.remove('active');
    } else {
        onlineSigning.classList.remove('active');
        offlineSigning.classList.add('active');
    }
    
    // 更新业务流程提醒
    updateProcessReminder();
}
```

#### 3. 业务流程提醒更新
```javascript
// 更新业务流程提醒
function updateProcessReminder() {
    const reminderContent = document.querySelector('.reminder-content');
    
    if (selectedAgent === 'yes') {
        if (selectedSigningMethod === 'online') {
            reminderContent.innerHTML = '<span class="highlight">法人</span>：点击确认>等待短信签约>提交提单';
        } else {
            reminderContent.innerHTML = '<span class="highlight">法人</span>：点击确认>线下签约>提交提单';
        }
    } else {
        if (selectedSigningMethod === 'online') {
            reminderContent.innerHTML = '<span class="highlight">经办人</span>：点击确认>法人短信授权>经办人短信签约>提交订单';
        } else {
            reminderContent.innerHTML = '<span class="highlight">经办人</span>：点击确认>线下签约>提交订单';
        }
    }
}
```

#### 5. 确认签约功能
```javascript
// 确认签约
function confirmSigning() {
    console.log('确认签约');
    console.log('经办人是否为法人:', selectedAgent);
    console.log('签约方式:', selectedSigningMethod);
    
    // 这里可以添加表单验证逻辑
    if (!selectedAgent || !selectedSigningMethod) {
        alert('请完善所有必填信息');
        return;
    }
    
    // 跳转到提交成功页面
    if (window.parent !== window) {
        window.parent.postMessage({ 
            type: 'contractUploadCompleted',
            data: {
                agent: selectedAgent,
                signingMethod: selectedSigningMethod
            }
        }, '*');
    } else {
        // 如果不在iframe中，可以跳转到下一个页面
        alert('签约信息已确认，进入提交成功页面');
    }
}
```

## 数据流程

### 1. 页面加载流程
1. 页面加载完成
2. 初始化默认选择状态
3. 更新业务流程提醒
4. 显示操作指南入口

### 2. 用户交互流程
1. 用户选择经办人身份（法人/经办人）
2. 用户选择签约方式（线上/线下）
3. 系统更新业务流程提醒
4. 用户查看操作指南（可选）
5. 用户确认签约信息

### 3. 提交流程
1. 验证必填信息完整性
2. 收集用户选择数据
3. 发送消息通知父窗口
4. 跳转到提交成功页面

## 使用说明

### 1. 页面访问
- 通过身份证上传页面跳转访问
- 支持移动端和桌面端访问
- 需要网络连接获取合同信息

### 2. 操作流程
1. 确认基本信息和套餐信息
2. 选择经办人身份（法人/经办人）
3. 选择签约方式（线上/线下）
4. 查看业务流程提醒
5. 点击确认按钮完成签约

### 3. 注意事项
- 经办人身份和签约方式为必选项
- 不同选择会显示不同的业务流程
- 可以查看操作指南了解详细步骤
- 确认后会自动跳转到成功页面
