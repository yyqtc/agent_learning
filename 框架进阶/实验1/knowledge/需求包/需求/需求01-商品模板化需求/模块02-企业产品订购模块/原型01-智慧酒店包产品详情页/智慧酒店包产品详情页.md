# 智慧酒店包产品详情页

## 页面概述

智慧酒店包产品详情页是企业产品订购模块的核心展示页面，主要用于展示智慧酒店包产品的详细信息，支持产品规格选择、价格展示和用户订购功能。该页面采用移动端优先设计，提供完整的产品浏览和订购体验。

## 功能特点

### 1. 产品展示系统
- **产品标题**：动态显示格式为 `【爱企商城】智慧酒店包{价格}元{套餐类型}`
- **产品图片**：轮播图展示，支持banner图片和详情图片
- **价格展示**：实时显示当前选择的价格和套餐类型
- **产品介绍**：包含商品介绍和温馨提示内容

### 2. 规格选择功能
- **套餐类型**：支持月包和年包选择
- **价格选项**：提供40元、50元、80元、100元、120元等价格档位
- **带宽选择**：支持100M、200M、300M、600M、1000M带宽选项
- **规格联动**：价格与带宽选项智能联动，确保配置合理性

### 3. 交互功能
- **Tab导航**：商品和详情两个Tab页面切换
- **规格弹窗**：点击"已选"或"立即预约"按钮打开规格选择弹窗
- **分享功能**：支持二维码分享和推广文案链接复制
- **消息通信**：支持与规格选择弹窗页面的数据交互

### 4. 用户体验优化
- **响应式设计**：适配移动端，最大宽度375px
- **动画效果**：页面加载淡入动画，弹窗滑入动画
- **状态管理**：实时更新选择状态和价格显示
- **操作反馈**：按钮点击状态变化，选择确认提示

### 核心功能模块

#### 1. Tab切换系统
```javascript
// Tab切换功能
document.querySelectorAll('.tab-item').forEach(tab => {
    tab.addEventListener('click', function() {
        // 移除所有active类
        document.querySelectorAll('.tab-item').forEach(t => t.classList.remove('active'));
        // 添加active类到当前tab
        this.classList.add('active');
        
        const tabIndex = this.dataset.tab;
        if (tabIndex === '1') {
            // 滚动到详情部分
            document.getElementById('contentBody').scrollIntoView({ 
                behavior: 'smooth',
                block: 'start'
            });
        } else {
            // 滚动到顶部
            window.scrollTo({ top: 0, behavior: 'smooth' });
        }
    });
});
```

#### 2. 规格选择弹窗
```javascript
// 规格选择弹窗
function showSpecModal() {
    // 创建iframe弹窗
    const iframe = document.createElement('iframe');
    const popupUrl = '智慧酒店包规格选择弹窗.html';
    iframe.src = popupUrl;
    iframe.style.cssText = `
        position: fixed;
        top: 0;
        left: 0;
        width: 100%;
        height: 100%;
        border: none;
        z-index: 10000;
        background-color: rgba(0, 0, 0, 0.5);
    `;
    iframe.id = 'specModalIframe';
    
    // 添加到页面
    document.body.appendChild(iframe);
}
```

## 数据流程

### 1. 产品信息获取
- **接口调用**：商品信息获取接口
- **数据来源**：省级产品信息表(t_iqimall_product)
- **数据内容**：产品基本信息、价格、规格等

### 2. 规格选择流程
1. 用户点击"已选"或"立即预约"按钮
2. 打开规格选择弹窗
3. 用户选择套餐类型、价格、带宽等
4. 系统验证选择的有效性
5. 更新页面显示的选择信息
6. 关闭弹窗返回详情页

### 3. 分享功能流程
1. 用户点击分享按钮
2. 显示分享选项弹窗
3. 选择二维码分享或复制推广文案链接
4. 执行相应的分享操作

## 接口设计

### 商品信息获取接口
- **接口名称**：商品信息获取接口
- **请求方式**：GET/POST
- **请求参数**：产品ID
- **返回数据**：产品详细信息、规格配置、价格信息

## 数据库表结构

### 省级产品信息表(t_iqimall_product)
- **表用途**：存储产品基本信息
- **主要字段**：产品ID、产品名称、价格、规格等

### 省级产品拓展信息表(t_iqimall_product_ext_attr)
- **表用途**：存储产品扩展属性
- **主要字段**：产品ID、属性类型、属性值等

## 使用说明

### 1. 页面访问
- 直接访问HTML文件
- 通过iframe嵌入其他页面
- 支持移动端和桌面端访问

### 2. 操作流程
1. 浏览产品信息和图片
2. 点击"已选"查看当前规格
3. 点击"立即预约"开始订购流程
4. 在规格选择弹窗中配置产品参数
5. 确认选择后进入信息填写页面

### 3. 注意事项
- 确保产品图片资源正确加载
- 规格选择需要符合SKU配置规则
- 分享功能需要配置正确的分享链接
