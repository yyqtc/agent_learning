# 智慧酒店包提交成功页面

## 页面概述

智慧酒店包提交成功页面是企业产品订购模块的最终反馈页面，以全屏弹窗形式展示订购提交成功的状态，提供用户友好的成功反馈和后续操作指引，包括返回首页和查询在途订单等功能。该页面采用简洁清晰的设计，确保用户能够明确了解订购状态。

## 功能特点

### 1. 成功状态展示
- **成功图片**：显示订购成功的视觉反馈图片
- **状态提示**：清晰的订购成功状态说明
- **用户引导**：友好的用户操作指引

### 2. 导航功能
- **返回首页**：提供返回首页的快捷入口
- **查询在途订单**：支持查看当前在途的订单状态
- **返回上一页**：支持返回上一级页面
- **关闭页面**：提供关闭当前页面的选项

### 3. 页面交互
- **固定导航栏**：顶部固定导航栏显示页面标题
- **响应式布局**：适配移动端显示
- **消息通信**：与父页面的完整消息传递机制
- **状态管理**：完整的页面状态和流程管理

### 4. 用户体验
- **视觉反馈**：清晰的成功状态视觉展示
- **操作便捷**：提供多种便捷的操作选项
- **信息完整**：展示完整的订购成功信息
- **流程闭环**：完成整个订购流程的闭环

### 核心功能模块

#### 1. 导航栏功能
```javascript
// 返回上一页
function goBack() {
    console.log('返回上一页');
    if (window.parent !== window) {
        window.parent.postMessage({ type: 'closeSuccessModal' }, '*');
    } else {
        window.history.back();
    }
}

// 关闭页面
function closePage() {
    console.log('关闭页面');
    if (window.parent !== window) {
        window.parent.postMessage({ type: 'closeSuccessModal' }, '*');
    } else {
        window.close();
    }
}
```

#### 2. 返回首页功能
```javascript
// 返回首页
function redirectToHome() {
    console.log('返回首页');
    
    // 通知父窗口关闭成功弹窗
    if (window.parent !== window) {
        window.parent.postMessage({ type: 'closeSuccessModal' }, '*');
    } else {
        // 如果不在iframe中，直接关闭窗口
        window.close();
    }
}
```

#### 3. 查询在途订单功能
```javascript
// 查询在途订单
function onTheWay() {
    console.log('查询在途订单');
    
    // 通知父窗口关闭成功弹窗并跳转到在途订单页面
    if (window.parent !== window) {
        window.parent.postMessage({ 
            type: 'closeSuccessModal',
            action: 'redirectToOnOrder'
        }, '*');
    } else {
        // 如果不在iframe中，直接跳转
        window.location.href = '智慧酒店包在途订单页面.html';
    }
}
```

## 接口设计

### 企业产品订购接口
- **接口名称**：企业产品订购接口
- **请求方式**：POST
- **请求参数**：订购信息、用户信息、合同信息等
- **返回数据**：订购结果、订单号、状态信息等

## 数据库表结构

### 省级产品信息表(t_iqimall_product)
- **表用途**：存储产品基本信息
- **主要字段**：产品ID、产品名称、价格、规格等

### 省级产品拓展信息表(t_iqimall_product_ext_attr)
- **表用途**：存储产品扩展属性
- **主要字段**：产品ID、属性类型、属性值等
