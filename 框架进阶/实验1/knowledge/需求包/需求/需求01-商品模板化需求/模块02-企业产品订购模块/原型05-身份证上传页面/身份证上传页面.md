# 身份证上传页面

## 页面概述

身份证上传页面是企业产品订购模块的重要身份验证组件，主要用于用户身份证件的上传和识别验证。该页面集成了证照识别技术，支持身份证正反面照片的上传、自动识别和信息提取，确保用户身份信息的准确性和合规性。

## 功能特点

### 1. 身份证上传功能
- **正面上传**：支持身份证正面照片上传
- **反面上传**：支持身份证反面照片上传
- **图片预览**：上传后提供图片预览功能
- **格式支持**：支持JPG、PNG等常见图片格式

### 2. 证照识别技术
- **自动识别**：基于OCR技术自动识别身份证信息
- **信息提取**：自动提取姓名、身份证号、有效期等关键信息
- **信息验证**：验证身份证信息的真实性和有效性
- **错误提示**：识别失败时提供清晰的错误提示

### 3. 用户交互设计
- **上传引导**：清晰的上传步骤和操作指引
- **进度显示**：上传和识别过程的进度反馈
- **重拍功能**：支持重新拍摄或重新上传
- **信息确认**：识别后允许用户确认和修改信息

### 4. 安全合规
- **数据加密**：上传的图片数据进行加密传输
- **隐私保护**：严格保护用户身份信息
- **合规要求**：符合相关法律法规要求
- **审计日志**：记录操作日志便于审计

### 核心功能模块

#### 1. 文件上传组件
```javascript
// 身份证上传功能
function uploadIdCard(type) {
    const input = document.createElement('input');
    input.type = 'file';
    input.accept = 'image/*';
    input.capture = 'camera';
    
    input.onchange = function(e) {
        const file = e.target.files[0];
        if (file) {
            // 验证文件类型和大小
            if (validateFile(file)) {
                uploadFile(file, type);
            } else {
                showError('请上传有效的身份证图片');
            }
        }
    };
    
    input.click();
}

// 文件验证
function validateFile(file) {
    const allowedTypes = ['image/jpeg', 'image/jpg', 'image/png'];
    const maxSize = 5 * 1024 * 1024; // 5MB
    
    if (!allowedTypes.includes(file.type)) {
        return false;
    }
    
    if (file.size > maxSize) {
        return false;
    }
    
    return true;
}
```

#### 2. 图片预览功能
```javascript
// 图片预览
function previewImage(file, type) {
    const reader = new FileReader();
    reader.onload = function(e) {
        const preview = document.getElementById(`${type}-preview`);
        preview.src = e.target.result;
        preview.style.display = 'block';
        
        // 显示识别按钮
        const recognizeBtn = document.getElementById(`${type}-recognize`);
        recognizeBtn.style.display = 'block';
    };
    reader.readAsDataURL(file);
}
```

#### 3. 证照识别接口
```javascript
// 证照识别
function recognizeIdCard(type) {
    const preview = document.getElementById(`${type}-preview`);
    const imageData = preview.src;
    
    // 显示识别进度
    showProgress('正在识别身份证信息...');
    
    // 调用证照识别接口
    fetch('/api/id-card/recognize', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
        },
        body: JSON.stringify({
            image: imageData,
            type: type // 'front' 或 'back'
        })
    })
    .then(response => response.json())
    .then(data => {
        hideProgress();
        if (data.success) {
            displayRecognizedInfo(data.result, type);
        } else {
            showError(data.message || '识别失败，请重新上传');
        }
    })
    .catch(error => {
        hideProgress();
        showError('网络错误，请重试');
        console.error('识别错误:', error);
    });
}
```

            </div>

#### 5. 完成状态检查
```javascript
// 检查完成状态
function checkCompletion() {
    const frontInfo = document.getElementById('front-info');
    const backInfo = document.getElementById('back-info');
    const submitBtn = document.getElementById('submitBtn');
    
    if (frontInfo.style.display === 'block' && backInfo.style.display === 'block') {
        submitBtn.disabled = false;
        submitBtn.textContent = '确认并继续';
        submitBtn.classList.add('enabled');
    }
}
```

#### 6. 表单提交
```javascript
// 提交身份证信息
function submitIdCard() {
    const frontInfo = getRecognizedInfo('front');
    const backInfo = getRecognizedInfo('back');
    
    if (!frontInfo || !backInfo) {
        showError('请完成身份证正反面识别');
        return;
    }
    
    // 显示提交进度
    showProgress('正在提交身份证信息...');
    
    // 提交数据
    fetch('/api/id-card/submit', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
        },
        body: JSON.stringify({
            frontInfo: frontInfo,
            backInfo: backInfo,
            frontImage: document.getElementById('front-preview').src,
            backImage: document.getElementById('back-preview').src
        })
    })
    .then(response => response.json())
    .then(data => {
        hideProgress();
        if (data.success) {
            // 跳转到合同上传页面
            redirectToContractUpload();
        } else {
            showError(data.message || '提交失败，请重试');
        }
    })
    .catch(error => {
        hideProgress();
        showError('网络错误，请重试');
        console.error('提交错误:', error);
    });
}
```

## 数据流程

### 1. 上传流程
1. 用户选择身份证图片文件
2. 验证文件类型和大小
3. 显示图片预览
4. 用户点击识别按钮

### 2. 识别流程
1. 调用证照识别接口
2. 上传图片数据
3. 服务器进行OCR识别
4. 返回识别结果
5. 展示识别信息

### 3. 提交流程
1. 验证正反面都识别完成
2. 收集所有识别信息
3. 提交到服务器
4. 跳转到下一页面

## 接口设计

### 证照识别接口
- **接口名称**：证照识别接口
- **请求方式**：POST
- **请求参数**：
  - image: 图片数据（base64编码）
  - type: 类型（front/back）
- **返回数据**：
  - success: 是否成功
  - result: 识别结果
  - message: 错误信息

### 身份证信息提交接口
- **接口名称**：身份证信息提交接口
- **请求方式**：POST
- **请求参数**：
  - frontInfo: 正面识别信息
  - backInfo: 反面识别信息
  - frontImage: 正面图片
  - backImage: 反面图片
- **返回数据**：
  - success: 是否成功
  - message: 结果信息

## 使用说明

### 1. 页面访问
- 通过温馨提示页面跳转访问
- 支持移动端和桌面端访问
- 需要网络连接进行识别

### 2. 操作流程
1. 点击身份证正面区域上传正面照片
2. 等待识别完成并确认信息
3. 点击身份证反面区域上传反面照片
4. 等待识别完成并确认信息
5. 点击确认并继续按钮

### 3. 注意事项
- 确保身份证照片清晰完整
- 支持拍照和相册选择
- 识别失败可以重新上传
- 需要正反面都识别完成才能继续
