# 智慧酒店包规格选择弹窗

## 页面概述

智慧酒店包规格选择弹窗是企业产品订购模块的核心交互组件，以弹窗形式展示产品规格选择界面，支持套餐类型、价格、带宽、电视和屏幕定制等选项的配置，并提供完整的信息填写流程。该弹窗采用底部弹出的设计，提供流畅的用户体验。

## 功能特点

### 1. 规格选择系统
- **套餐类型选择**：支持月包和年包两种套餐类型
- **价格档位**：月包(40/50/80/100/120元)、年包(400/500/800/1000/1200元)
- **带宽选择**：100M、200M、300M、600M、1000M五个档位
- **电视配置**：商务电视IPTV选项
- **屏幕定制**：屏幕定制标准版选项

### 2. 智能联动机制
- **价格带宽联动**：根据套餐类型和价格自动筛选可用带宽
- **SKU配置管理**：预定义的价格带宽组合规则
- **状态同步**：选择结果实时同步到父页面和子页面

### 3. 弹窗交互设计
- **底部弹出**：从屏幕底部滑入的弹窗效果
- **遮罩层**：半透明黑色背景遮罩
- **关闭机制**：支持点击关闭按钮、ESC键、点击遮罩关闭
- **消息通信**：与父页面和子页面的完整消息传递机制

### 4. 信息填写集成
- **无缝跳转**：规格选择完成后直接进入信息填写页面
- **数据传递**：选择结果完整传递给信息填写页面
- **流程管理**：完整的订购流程控制和状态管理

// 选择套餐类型
function selectPacketType(type, element) {
    // 移除所有active类
    document.querySelectorAll('.packet-btn').forEach(btn => btn.classList.remove('active'));
    // 添加active类到当前按钮
    element.classList.add('active');

    // 更新价格选项

#### 2. 价格选项动态生成
```javascript
// 更新价格选项
function updatePriceOptions() {
    const priceOptionsContainer = document.getElementById('priceOptions');
    const currentPackageType = currentSelection.packetType;
    
    // 根据套餐类型获取价格列表
    const prices = currentPackageType === 'month' 
        ? ['40', '50', '80', '100', '120']
        : ['400', '500', '800', '1000', '1200'];
    
    // 清空现有选项
    priceOptionsContainer.innerHTML = '';
    
    // 生成新的价格选项
    prices.forEach((price, index) => {
        const option = document.createElement('div');
        option.className = `option ${index === 0 ? 'isActive' : ''}`;
        option.onclick = () => selectPrice(parseInt(price), option);
        option.innerHTML = `<span class="name">￥${price}</span>`;
        priceOptionsContainer.appendChild(option);
    });
}
```

#### 3. SKU规格联动配置
```javascript
// SKU规格联动配置
const skuConfig = {
    'month': {
        '40': ['100M'],
        '50': ['200M'],
        '80': ['300M'],
        '100': ['600M'],
        '120': ['1000M']
    },
    'year': {
        '400': ['100M'],
        '500': ['200M'],
        '800': ['300M'],
        '1000': ['600M'],
        '1200': ['1000M']
    }
};

// 更新带宽选项状态
function updateBandwidthOptions() {
    const currentPackageType = currentSelection.packetType;
    const currentPrice = currentSelection.price;
    
    // 获取当前价格对应的可用带宽
    const availableBandwidths = skuConfig[currentPackageType][currentPrice.toString()] || [];
    
    // 更新所有带宽按钮状态
    document.querySelectorAll('.bandwidth-btn').forEach(btn => {
        const bandwidth = btn.textContent.trim();
        
        if (availableBandwidths.includes(bandwidth)) {
            // 可用带宽
            btn.classList.remove('disabled');
            btn.style.opacity = '1';
            btn.style.cursor = 'pointer';
        } else {
            // 不可用带宽
            btn.classList.add('disabled');
            btn.style.opacity = '0.4';
            btn.style.cursor = 'not-allowed';
        }
    });
}
```

#### 4. 信息填写弹窗集成
```javascript
// 显示信息填写弹窗
function showInfoFormModal() {
    // 隐藏规格选择弹窗
    document.querySelector('.popup-container').style.display = 'none';
    
    // 创建iframe来加载信息填写页面
    const modal = document.getElementById('infoFormModal');
    const iframe = document.createElement('iframe');
    iframe.src = '智慧酒店包信息填写页面.html';
    iframe.style.width = '100%';
    iframe.style.height = '100%';
    iframe.style.border = 'none';
    iframe.style.borderRadius = '20px 20px 0 0';
    
    // 清空现有内容并添加iframe
    modal.innerHTML = '';
    modal.appendChild(iframe);
    
    // 显示弹窗
    modal.classList.add('show');
    
    // 监听iframe加载完成
    iframe.onload = function() {
        // 将选择数据传递给iframe
        const selectionData = encodeURIComponent(JSON.stringify(currentSelection));
        const message = {
            type: 'updateSelection',
            data: selectionData
        };
        iframe.contentWindow.postMessage(message, '*');
    };
}
```

#### 5. 消息通信机制
```javascript
// 监听来自iframe的消息
window.addEventListener('message', function(event) {
    if (event.data.type === 'closeInfoForm') {
        closeInfoForm();
    } else if (event.data.type === 'closeSuccessModal') {
        closeSuccessModal();
    }
});

// 关闭弹窗并返回详情页
function closeModal() {
    // 如果在iframe中，向父窗口发送消息关闭弹窗
    if (window.self !== window.top && window.parent) {
        window.parent.postMessage({ type: 'closeModal' }, '*');
    } else {
        // 否则，尝试直接关闭弹窗或导航回详情页
        const modal = document.getElementById('specModal');
        if (modal) {
            modal.classList.remove('show');
        } else {
            const detailPageUrl = window.location.pathname.replace('智慧酒店包规格选择弹窗.html', '智慧酒店包产品详情页.html');
            window.location.href = detailPageUrl;
        }
    }
}
```

## 数据流程

### 1. 规格选择流程
1. 用户打开规格选择弹窗
2. 选择套餐类型（月包/年包）
3. 系统动态更新价格选项
4. 用户选择价格档位
5. 系统根据SKU配置更新可用带宽
6. 用户选择带宽、电视、屏幕定制
7. 点击确认按钮进入信息填写页面

### 2. 数据传递流程
1. 规格选择完成后收集所有选择数据
2. 通过postMessage将数据传递给信息填写页面
3. 信息填写页面接收并更新产品信息显示
4. 完成整个订购流程的数据流转

### 3. 状态管理
- **当前选择状态**：实时维护用户的选择状态
- **SKU配置验证**：确保选择组合的有效性
- **页面状态同步**：与父页面和子页面保持状态一致

## 接口设计

### 商品信息获取接口
- **接口名称**：商品信息获取接口
- **请求方式**：GET/POST
- **请求参数**：产品ID
- **返回数据**：产品详细信息、规格配置、价格信息

## 数据库表结构

### 省级产品信息表(t_iqimall_product)
- **表用途**：存储产品基本信息
- **主要字段**：产品ID、产品名称、价格、规格等

### 省级产品拓展信息表(t_iqimall_product_ext_attr)
- **表用途**：存储产品扩展属性
- **主要字段**：产品ID、属性类型、属性值等

## 使用说明

### 1. 弹窗调用
- 通过父页面的showSpecModal()函数调用
- 支持iframe嵌入和独立页面访问
- 自动适配移动端和桌面端

### 2. 操作流程
1. 选择套餐类型（月包/年包）
2. 选择价格档位
3. 选择带宽（根据价格自动筛选）
4. 确认电视和屏幕定制选项
5. 点击确认按钮进入信息填写页面

### 3. 注意事项
- 价格和带宽选项有联动关系，需要符合SKU配置
- 年包价格是月包价格的10倍
- 选择完成后会自动跳转到信息填写页面
