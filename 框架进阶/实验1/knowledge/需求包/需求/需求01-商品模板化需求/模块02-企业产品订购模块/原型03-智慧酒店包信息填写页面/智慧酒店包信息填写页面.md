# 智慧酒店包信息填写页面

## 页面概述

智慧酒店包信息填写页面是企业产品订购模块的信息收集组件，以底部弹出的形式展示用户信息填写界面，支持安装地址、详细地址、联系方式和备注信息的录入，并集成产品规格信息展示和提交成功流程。该页面采用移动端优先设计，提供流畅的信息录入体验。

## 功能特点

### 1. 信息收集功能
- **安装地址**：城市选择和具体楼宇选择
- **详细地址**：楼栋和房间号的分段输入
- **联系方式**：姓名和电话号码的并行输入
- **备注信息**：可选的备注说明输入

### 2. 产品信息展示
- **产品缩略图**：显示产品图片
- **价格信息**：实时显示当前选择的价格和套餐类型
- **规格详情**：展示已选择的套餐类型、带宽、电视、屏幕定制等信息
- **动态更新**：根据规格选择结果动态更新显示内容

### 3. 表单验证机制
- **必填项验证**：安装地址、详细地址、姓名、电话为必填项
- **格式验证**：手机号码格式验证
- **实时反馈**：输入过程中的即时验证反馈
- **错误提示**：清晰的错误信息提示

### 4. 弹窗交互设计
- **底部弹出**：从屏幕底部滑入的弹窗效果
- **返回功能**：支持返回上一级页面
- **提交流程**：完整的表单提交和成功反馈流程
- **消息通信**：与父页面的完整消息传递机制

#### 5. 消息通信机制
```javascript
// 监听来自父窗口的消息
window.addEventListener('message', function(event) {
    console.log('=== 接收到父窗口消息 ===');
    console.log('消息来源:', event.origin);
    console.log('消息数据:', event.data);
    
    if (event.data && event.data.type === 'updateSelection') {
        console.log('开始处理updateSelection消息');
        
        try {
            const decodedData = decodeURIComponent(event.data.data);
            const selectionData = JSON.parse(decodedData);
            console.log('解析后的选择数据:', selectionData);
            updateProductInfo(selectionData);
        } catch (error) {
            console.error('解析选择数据失败:', error);
        }
    }
});
```

#### 6. 产品信息更新
```javascript
// 更新产品信息显示
function updateProductInfo(selectionData) {
    console.log('=== 开始更新产品信息 ===');
    
    const packetTypeText = selectionData.packetType === 'month' ? '月包' : '年包';
    const currentPrice = selectionData.packetType === 'month' ? 
        selectionData.price : 
        selectionData.price * 10;
    
    // 更新产品名称显示
    const productNameElement = document.getElementById('productName');
    if (productNameElement) {
        const newName = `智慧酒店包${currentPrice}元${packetTypeText}`;
        productNameElement.textContent = newName;
    }
    
    // 更新产品价格显示
    const priceElement = document.querySelector('.current-price');
    if (priceElement) {
        priceElement.textContent = `¥${currentPrice}`;
    }
    
    // 更新套餐类型显示
    const packetTypeElement = document.querySelector('.packet-type');
    if (packetTypeElement) {
        packetTypeElement.textContent = packetTypeText;
    }
    
    // 更新底部总价显示
    const totalPriceElement = document.querySelector('.total-price');
    if (totalPriceElement) {
        totalPriceElement.textContent = `¥${currentPrice}${packetTypeText}`;
    }
    
    // 更新规格详情
    const specElements = {
        'selectedPacketType': packetTypeText,
        'selectedBandwidth': selectionData.bandwidth,
        'selectedTV': selectionData.tv,
        'selectedScreen': selectionData.screen
    };
    
    Object.keys(specElements).forEach(id => {
        const element = document.getElementById(id);
        if (element) {
            element.textContent = specElements[id];
        }
    });
}
```

```javascript
function showSuccessModal() {
    console.log('显示提交成功弹窗');
    
    // 创建iframe来加载提交成功弹窗页面
    const container = document.getElementById('successModalContainer');
    const iframe = document.createElement('iframe');
    iframe.src = '智慧酒店包提交成功弹窗.html';
    iframe.style.width = '100%';
    iframe.style.height = '100%';
    iframe.style.border = 'none';
    
    // 清空现有内容并添加iframe
    container.innerHTML = '';
    container.appendChild(iframe);
    
    // 显示弹窗
    container.classList.add('show');
    
    // 监听iframe加载完成
    iframe.onload = function() {
        console.log('提交成功弹窗页面已加载');
    };
}
```

#### 8. 关闭弹窗功能
```javascript
// 关闭弹窗
function closeModal() {
    console.log('关闭弹窗');
    
    // 通知父窗口关闭弹窗
    if (window.parent !== window) {
        window.parent.postMessage({ type: 'closeInfoForm' }, '*');
    } else {
        // 添加关闭动画
        const container = document.querySelector('.page-container');
        container.classList.remove('show');
        container.style.animation = 'slideDown 0.3s ease-in forwards';
        
        setTimeout(() => {
            window.close();
        }, 300);
    }
}
```

## 数据流程

### 1. 数据接收流程
1. 从规格选择弹窗接收选择数据
2. 解析JSON格式的选择信息
3. 更新页面上的产品信息显示
4. 保持数据的一致性和准确性

### 2. 表单数据收集
1. 收集安装地址信息（城市、楼宇）
2. 收集详细地址信息（楼栋、房间号）
3. 收集联系方式（姓名、电话）
4. 收集备注信息（可选）
5. 验证必填项和格式

### 3. 提交流程
1. 验证表单数据的完整性
2. 显示提交成功弹窗
3. 通过iframe加载成功页面
4. 完成整个订购流程

## 接口设计

### 商品信息获取接口
- **接口名称**：商品信息获取接口
- **请求方式**：GET/POST
- **请求参数**：产品ID
- **返回数据**：产品详细信息、规格配置、价格信息

### 地图信息获取接口
- **接口名称**：地图信息获取接口
- **请求方式**：GET/POST
- **请求参数**：地址关键词
- **返回数据**：地址建议、楼宇信息等

### 用户信息获取接口
- **接口名称**：用户信息获取接口
- **请求方式**：GET/POST
- **请求参数**：用户ID
- **返回数据**：用户基本信息、联系方式等

## 数据库表结构

### 省级产品信息表(t_iqimall_product)
- **表用途**：存储产品基本信息
- **主要字段**：产品ID、产品名称、价格、规格等

### 省级产品拓展信息表(t_iqimall_product_ext_attr)
- **表用途**：存储产品扩展属性
- **主要字段**：产品ID、属性类型、属性值等

## 使用说明

### 1. 页面调用
- 通过规格选择弹窗的确认按钮调用
- 支持iframe嵌入和独立页面访问
- 自动适配移动端和桌面端

### 2. 操作流程
1. 填写安装地址（城市和楼宇）
2. 填写详细地址（楼栋和房间号）
3. 填写姓名和联系电话
4. 填写备注信息（可选）
5. 查看产品信息确认
6. 点击提交预约按钮

### 3. 注意事项
- 安装地址、详细地址、姓名、电话为必填项
- 手机号码需要符合标准格式
- 产品信息会根据规格选择自动更新
- 提交后会自动跳转到成功页面
