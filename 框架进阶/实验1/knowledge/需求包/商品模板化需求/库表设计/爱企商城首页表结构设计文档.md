# 爱企商城首页表结构设计文档

## 概述

本文档描述了爱企商城首页模块的数据库表结构设计，包含8个核心表，用于管理首页模板、组件、资源、商品等内容。

## 表结构说明

## 表关系说明

### 主要关系
1. **t_template_instance** → **t_template_component_instance** (一对多)
   - 一个模板可以包含多个组件实例
   - 通过 template_id 关联

2. **t_component_base** → **t_template_component_instance** (一对多)
   - 一个基础组件可以被多个模板组件实例使用
   - 通过 component_base_id 关联

3. **t_template_component_instance** → **t_component_resource_relation** (一对多)
   - 一个组件实例可以关联多个资源
   - 通过 component_instance_id 关联

4. **t_image_resource** → **t_component_resource_relation** (一对多)
   - 一个图片资源可以被多个组件实例使用
   - 通过 resource_id 关联，resource_type = 'IMAGE'

5. **t_navigation_resource** → **t_component_resource_relation** (一对多)
   - 一个导航资源可以被多个组件实例使用
   - 通过 resource_id 关联，resource_type = 'NAVIGATION'

6. **t_iqimall_product** → **t_iqimall_product_sku** (一对多)
   - 一个产品可以包含多个规格
   - 通过 product_id 关联

7. **t_iqimall_product** → **t_component_resource_relation** (一对多)
   - 一个产品可以被多个组件实例使用
   - 通过 resource_id 关联，resource_type = 'PRODUCT'

8. **t_iqimall_product_sku** → **t_component_resource_relation** (一对多)
   - 一个产品规格可以被多个组件实例使用
   - 通过 resource_id 关联，resource_type = 'PRODUCT_SKU'

### 业务逻辑
- 系统支持多级模板管理，可以根据地市、用户类型、场景类型配置不同的首页模板
- 组件采用基础配置+实例配置的方式，支持灵活的个性化定制
- 资源与组件实例通过关系表关联，支持动态配置展示内容
- 商品管理支持产品与规格的层级结构，一个产品可以包含多个规格
- 商品可以通过组件实例在首页进行展示，支持商品推荐、热卖等功能
- 所有表都采用软删除机制，通过 delete_flag 字段控制

## 数据类型说明

- **varchar(n)**: 可变长度字符串，最大长度n
- **text**: 长文本类型
- **int4**: 32位整数
- **int8**: 64位整数
- **bool**: 布尔类型
- **timestamp**: 时间戳类型
- **bpchar(1)**: 固定长度字符，长度1
- **jsonb**: JSON二进制格式，支持索引和查询

---

## 默认值说明

- **is_enabled**: 默认为 true
- **sort_order**: 默认为 0 或 1
- **is_default**: 默认为 false
- **delete_flag**: 默认为 '0' (未删除)
- **create_time/update_time**: 默认为 CURRENT_TIMESTAMP
- **nav_level**: 默认为 1
